# Brave Domain Manager

A desktop tool for managing Brave browser's domain blocklist in the Windows registry.

**This project is being rewritten from Python/PyQt5 to Electron + React + TypeScript.**
The rewrite lives under `src/` as it's built out. The previous PyQt5 application has
been archived to [`legacy/`](legacy/) and is no longer maintained, but remains there
as a functional reference during the transition.

Documentation site: https://cbgithub7.github.io/Brave-Domain-Manager/ (source in [`docs/`](docs/))
